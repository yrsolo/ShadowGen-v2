# Documentation Governance

## Principle

Documentation is a navigation system, not a dump of notes.

## Layers

- root overview in `README.md`
- quick orientation in `docs/overview/`
- technical detail in `docs/architecture/` and `docs/reference/`
- temporary work in `work/`

## Rules

1. Keep one document focused on one role
2. Do not move working notes into permanent docs
3. Prefer updating existing docs over creating duplicates
