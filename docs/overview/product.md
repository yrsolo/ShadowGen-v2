# Product Overview

## What It Is

ShadowGen v2 prepares product images for catalog use. The desired end result is a clean white background with a soft grounding shadow under the object.

## Who It Is For

- marketplace content teams
- internal photo studios
- e-commerce automation pipelines

## Problem It Solves

Teams often receive raw photos with inconsistent backgrounds and need a repeatable post-processing step. This project aims to turn that cleanup into a service instead of manual editing.

## Main Scenarios

- upload an already cut out object and render a marketplace-style output
- later: upload a raw photo and remove the background automatically
- use the same processing pipeline from scripts, APIs, or jobs

## Key Parts Of The System

- HTTP API for ingestion and orchestration
- application pipeline for composition rules
- adapters for segmentation and file storage
